# DSE Physics Mock MC Practice

Practice site for HKDSE Physics multiple-choice questions taken from publisher mock papers:
- Pearson (Active Physics) 2025 and 2026 – Paper 1A and Paper 2 elective MCs, English and Chinese
- OUP 2024 and 2023 (Set 1) – Paper 1A and Paper 2 elective MCs, Chinese only

Students choose topics and the number of questions. Worked solutions are shown after each answer.

- `index.html` – the site (question list is embedded in the page)
- `questions.json` – the same question list, for reference
- `q/` – question images, `s/` – solution images (`<paper>-<year>-<no>-<C|E>.png`)

For internal teaching use only.
